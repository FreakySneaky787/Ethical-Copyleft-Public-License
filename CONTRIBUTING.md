# Contributing to the ECPL

Thanks for helping to improve the Ethical Copyleft Public License!

## How to contribute

- **Questions** about how the ECPL applies to your project: ask in the [Discussions](../../discussions) (Q&A).
- **Mistakes in the text** (typos, unclear wording, contradictions): open an issue with the
  "Mistake in the license text" form.
- **Suggestions for a future version**: open an issue with the "Suggestion for a future version" form,
  or start a discussion under Ideas first.
- Pull requests are welcome for typos and the README. For changes to the terms, please open an issue first.

## Who decides about changes

The ECPL is maintained by its author. **The author may change the license text and publish new versions at
any time**, with or without a public discussion first. Suggestions are welcome, but there is no right to have a
suggestion accepted.

By submitting a suggestion, wording or pull request, you agree that it may be used, changed and published as part
of any version of the ECPL, without a claim to compensation or credit.

## What a new version means for existing projects

New versions are published as [releases](../../releases) with a new version number (for example v1.3).
A project that is licensed under a specific version (for example ECPL v1.2) stays under that version. A new version
applies to a project only if its copyright holder chooses to use it.

## Please note

Discussions and answers in this repository are not legal advice. If you rely on the ECPL for important work,
have it reviewed by a lawyer in your jurisdiction.
